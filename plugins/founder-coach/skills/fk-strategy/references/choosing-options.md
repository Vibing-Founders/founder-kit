# Choosing between options

For questions like "agencies or solo consultants?", "done-for-you or self-serve first?",
"photographers or videographers?". The founder decides; the skill makes the trade-off visible
and gives a view.

## Steps

1. **Name the options** (usually two, at most three) and the decision in one line. If an
   obvious option is missing (often "neither yet: do more interviews first"), add it.
2. **Lay out each option against the founder's constraints and evidence**, in a short table:

   | | Option A | Option B |
   |---|---|---|
   | Evidence so far (what real people said or did) | | |
   | Fit with hours, skills, runway (profile) | | |
   | Can the founder reach them? How? | | |
   | How fast it reaches a first payment | | |
   | What they use today instead | | |
   | Biggest risk | | |

   Use only what the profile, journey, research and the founder have given you. Write
   "unknown" rather than guessing, and do not size the market for either option.
3. **Make the trade-offs explicit** in plain sentences: "If you pick A, you are not doing B
   for now, because…". Each option should have a cost the founder can see.
4. **Recommend one**, with the reason, and turn it into a strategic bet with **kill criteria**
   (number, date, observed behaviour) that would make the founder switch to the other option.
5. **Let the founder decide.** Ask which they choose. Do not write the choice into
   `strategy.md` as decided until they have said so; until then, record it as an open question
   (or, if they ask you to, as a draft bet marked "proposed").
6. **When they decide**, update `strategy.md`: wedge, bets, "not doing yet" (the option not
   chosen goes here with its "because"), and a change log entry. If it changes the stage or the
   current bet, say so and suggest a coach check-in.

## Where evidence is thin

If neither option has real evidence behind it, say so. The best recommendation may be a
cheap test that tells them apart (five conversations with each group, two landing pages with a
price), with a date to decide by. Point at `customer-research:fk-segments` for desk research on
which group to talk to first, and `fk-icp` once there are transcripts.
